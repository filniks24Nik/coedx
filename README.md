# Белый кадр

## Онлайн-демонстрация через GitHub Pages

В репозитории откройте Settings → Pages → Build and deployment → Source → GitHub Actions. После отправки в main workflow `Publish demo to GitHub Pages` публикует только index.html, без Python-сервера и секретов. При первом включении запустите workflow вручную через Actions → Publish demo to GitHub Pages → Run workflow, если автоматический запуск уже завершился ошибкой. Итоговый адрес появится в Settings → Pages и результате deployment.

В демонстрации работают локальное кадрирование и печатные листы; ИИ недоступен. Фото не отправляются на сервер. Для полноценного ИИ нужен отдельный серверный хостинг; GitHub Pages не запускает Python.

Прототип русскоязычного сервиса подготовки фото. Запуск:

```sh
python3 -m venv /tmp/bely-kadr-venv
/tmp/bely-kadr-venv/bin/pip install -r requirements.txt
/tmp/bely-kadr-venv/bin/uvicorn server:app --host 127.0.0.1 --port 8000
```

Без ключа работают загрузка JPEG/PNG/WebP, кадрирование, масштаб, экспорт отдельного фото и листа 10×15 см с метками реза при 300 пикселях на дюйм. Печатать при масштабе 100%, без подгонки; контрольный отрезок должен быть 10 мм. PNG содержит физическое разрешение pHYs. Проверьте размер линейкой перед использованием.

ИИ: сервер читает OPENAI_API_KEY из окружения и обращается к OpenAI Images Edit API (gpt-image-1). Не храните ключ в браузере или репозитории. Доступ к модели, оплата, доступность поставщика для вашего региона и сетевой доступ api.openai.com нужны отдельно. Обработка платная; без ключа она явно отключена. Генерация не проверена живым запросом в этой среде.

Фотографии не записываются сервером на диск. При ИИ-обработке фото передаётся внешнему поставщику после согласия пользователя; применяются его условия хранения. Документный режим не запрашивает косметическую ретушь и смену одежды. Портретный режим не предназначен для официальных документов. Даже документный режим может изменить детали: сравните результат с оригиналом. Нет распознавания лица, автоматической проверки положения головы или гарантии принятия фото ведомством. Формат 35×45 мм — геометрический шаблон, не подтверждение актуальных требований МВД/консульств. До публикации нужны проверенные ссылки на требования для каждого документа, юридические тексты/согласия по персональным данным, аутентификация, лимиты, защита от злоупотребления платным API и проверка региональной доступности поставщика. Сервер предназначен для локальной разработки.
